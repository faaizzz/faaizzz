## Featured projects

### [AWS AI Gateway with LiteLLM](https://github.com/faaizzz/aws-ai-gateway-with-litellm-poc)
A governed LLM gateway on AWS. A team onboards an AI use case by editing one YAML file and opening a pull request; Terraform turns it into least-privilege IAM, an approved model route, a route-scoped gateway key and a budget, and the gateway enforces them at runtime.

`Terraform` `LiteLLM` `Amazon Bedrock` `ECS Fargate` `Langfuse` `GitHub Actions`

### [BYOP — Bring Your Own Podcast](https://github.com/faaizzz/Bring-Your-Own-Podcast-BYOP)
A self-hosted app that turns the feeds, pages and searches you care about into a scheduled, multi-speaker AI podcast with its own RSS feed. Any LLM or voice provider, or run everything locally; cost tracking and review before publishing.

`Python` `FastAPI` `Celery` `PostgreSQL` `React` `TypeScript` `Docker`
